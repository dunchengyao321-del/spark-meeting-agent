# 飞书会议语音智能体 · 使用说明（非研发版）

智能体进入你的飞书会议后：能**听**会议室说话、能**开口回答**、能**看聊天消息并回帖**、能**看投屏内容**。

## 使用前准备（只需一次）

1. 电脑装有 **Chrome 浏览器**。
2. **星火控制台服务**已在运行：浏览器能打开 `http://127.0.0.1:8765/`（通常它由 launchd 常驻，无需手动管）。
3. 拿到一个 **9 位飞书会议号**（发起会议后可见）。

## 三步使用

1. **双击运行** `start_agent.sh`（或在终端执行 `./start_agent.sh 会议号`）。
2. 浏览器自动打开会议页：首次需要**扫码登录飞书**（之后免登），进入会议（如有等候室请主持人放行）。聊天面板会**自动展开**。
3. 开始用：
   - **说话**：直接对会议说问题，智能体语音回答；
   - **发文字**：在会议聊天里发消息，智能体**语音回答 + 文字回帖**；
   - **问投屏**：有人共享屏幕时问"你看一下投屏，屏幕上是什么"；
   - **让它停**：说"别说了"或在聊天里发"停下"。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 智能体没反应 | 确认你说话音量够大、手机麦克风没静音；聊天消息**不要重复发一字不差的内容**（重复内容会被去重） |
| 听到自己/它自己打断自己 | 你是用扬声器外放+开麦导致的回声：**戴耳机**，或它回答时把你的麦克风静音 |
| 想让它别说了 | 说"别说了"或聊天发"停下"，立即静音 |
| 要重新进别的会 | 终端里 Ctrl+C 停掉，重新 `./start_agent.sh 新会议号` |
| 完全不发声 | 看终端日志；确认会议工具栏里麦克风图标是打开状态 |

## 注意事项

- 声音连贯性依赖网络与电脑性能，回答延迟正常在 **2 秒内**。
- 智能体只听、只说，**不会录音**，音频实时流过本机（ASR/LLM/TTS 走你配置的火山/豆包接口）。
- 关闭：终端按 **Ctrl+C** 退出智能体；桥接服务可用 `kill $(cat bridge.pid)` 停止。
