# 飞书会议语音智能体 · 交付清单（T20）

> 版本：2026-09-01 · 核心链路全部实测通过（双向音频 / 聊天双向 / 投屏视觉 / 唤醒门控 / KB 与 MCP 工具）

## 一、快速开始（三步）

```bash
cd 02-研发实现
./start_agent.sh 会议号     # 例：./start_agent.sh 378552853
```

1. 浏览器打开会议页 → 首次扫码登录飞书（之后免登）→ 进入会议；
2. 监控页：**http://127.0.0.1:8765/meeting.html**（实时对话流 / 投屏画面 / 配置）；
3. 智能体平时只听并记录，喊"**星火**"才应答（语音/聊天同规则）。

详细说明见 [使用说明.md](使用说明.md)（非研发同事用）。

## 二、交付物清单

| 文件/目录 | 作用 |
|---|---|
| `start_agent.sh` | 一键启动：依赖自检 → 拉起桥接 → 打开智能体浏览器 |
| `run_agent.py` | Playwright 启动器：flags/权限/注入/入会检测/CDP 调试端口 |
| `shim.js` | 页面注入核心：合成麦克风轨 / 远端轨采集 / 聊天采集 / 投屏截帧 / 抖动缓冲 |
| `features/chat_reply.js` | 特性：智能体答复代发到会议聊天框（随启动自动加载） |
| `bridge_server.py` | 桥接服务：双向 PCM / 控制消息 / 监控广播 / 打断清空 |
| `pipeline_adapter.py` | 管线适配器：重采样 / 实时整流 / 会议记录落盘 / 事件转发 / 防自答 |
| `hot_inject.py` | 免重启热注入工具（CDP，调试用） |
| `test_loopback.html` | 验证工具：不进会议的回环自测页 |
| `config.example.json` | 配置模板（复制为 `agent_config.json` 修改） |
| `使用说明.md` | 非研发版使用文档 |
| `README.md` | 研发版架构与联调文档 |
| `联调记录-T09.md` `联调记录-T11-T12.md` | 真实联调问题档案 |
| `transcripts/` | 运行产物：会议记录 JSONL（按日期） |

运行时生成、**不属于交付**（已 gitignore）：`.agent-profile/`、`bridge.log`、`bridge.pid`、`__pycache__/`。
